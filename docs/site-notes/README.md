# 站点资源备忘（site-notes）

存放**非泛用、但提供便利**的环境信息：特定网段/机器的共享盘、权重路径、代码仓位置、资源清单等。
与 `docs/` 根目录通用指南的分工：

| 类型 | 位置 | 内容 |
|------|------|------|
| 通用操作指南 | `docs/*.md` | 教 AI 怎么做（SSH、容器、NPU 清理、拉镜像…） |
| 站点资源备忘 | `docs/site-notes/*.md` | 告诉 AI 某个环境里有什么（共享盘、资源路径…） |

## 命名规则

- 主文件：`<环境或网段>-resources.md`，如 `blue-zone-resources.md`
- 同一环境的其他主题：`<环境或网段>-<主题>.md`，如 `blue-zone-weights.md`

## 标准结构（模板）

```markdown
# <环境名> 资源备忘

> 适用范围：<服务器/网段> ｜ 验证日期：YYYY-MM-DD ｜ 维护：遇新信息主动更新

## 共享盘 / 挂载

| 挂载点 | 来源 | 容量 | 用途 |

## 资源清单（权重 / 数据集 / 代码仓）

## 常见路径速查

## 注意事项

## 更新记录
```

## 安全规则（重要）

本仓库是 **public**（GitHub xuchi-0808/blue-server-toolkit）：

- **禁止**写入内网具体 IP、账号、口令、工号等敏感信息
- 用服务器别名（s1-s8）、网段（如 192.168 段）、NFS 主机名代替具体地址
- 确需完整敏感信息（真实 IP/账号）时，放本机 `~/.blue_server_toolkit/docs/site-notes/`（不入库）
- 更新后同步约定见 SKILL.md「维护与同步」
